📍 Почни звідси

Що означає розв’язати систему?

Розв’язком системи нерівностей називають значення змінної, за якого кожна нерівність системи правильна. Тому потрібно знайти спільні розв’язки всіх нерівностей — тобто перетин проміжків.

{2x > 24,3x < 39.
Перша нерівність: 2x > 24, тому x > 12.
Друга нерівність: 3x < 39, тому x < 13.
Разом: число має бути більшим за 12 і меншим за 13.
x > 12x < 13спільна частина

Відповідь: 12 < x < 13, або x ∈ (12; 13).

Зверни увагу: 12 і 13 не входять до відповіді, бо нерівності строгі (> та <). На координатній прямій у цих точках — порожні кружечки.
🧭 Алгоритм

П’ять кроків для будь-якої системи

1. Розв’яжи першу нерівність, виконуючи однакові перетворення з обома частинами.
2. Розв’яжи другу нерівність. Якщо ділиш або множиш на від’ємне число, зміни знак нерівності на протилежний.
3. Запиши кожну відповідь у вигляді нерівності або проміжку.
4. Познач обидва проміжки на одній координатній прямій і знайди спільну частину.
5. Запиши відповідь. Якщо спільної частини немає — розв’язків немає.
Типова помилка. Після ділення на від’ємне число знак нерівності змінюється. Наприклад, −4x < 8
x > −2, а не x < −2.
📖 Розбираємо завдання з підручника

Вправа № 7.14 (1)

Підручник Істера, сторінка 56. Тут розберемо повний шлях від системи до відповіді.

{2,6 + x > 5(x + 1) − 6,2(x − 0,4) − x < 3x − 0,5.

Крок 1. Розв’язуємо першу нерівність

Розкриваємо дужки: 2,6 + x > 5x + 5 − 6
Зводимо числа справа: 2,6 + x > 5x − 1
Переносимо x в праву частину, а числа — в ліву: 3,6 > 4x
Ділимо на 4: 0,9 > x, тобто x < 0,9.

Крок 2. Розв’язуємо другу нерівність

Розкриваємо дужки: 2x − 0,8 − x < 3x − 0,5
Зводимо подібні доданки: x − 0,8 < 3x − 0,5
Переносимо x вправо, числа вліво: −0,3 < 2x
Ділимо на 2: x > −0,15.

Крок 3. Знаходимо перетин

Маємо одночасно x < 0,9 і x > −0,15. Отже, x лежить між −0,15 та 0,9; обидві межі не включаємо.

Перша нерівністьДруга нерівністьПеретин

Відповідь: x ∈ (−0,15; 0,9).

Спробуй самостійно

Тренувальна вправа 1

Який проміжок є перетином умов x < 4 та x ≥ −2?

У попередній тренувальній вправі зверни увагу на дужки: умова x ≥ −2 включає число −2. Отже, правильна відповідь — [−2; 4).

Вправа № 7.15 (1)

Тут важливо помітити, що система може не мати розв’язків.

{2(x + 3) − 4 < x − 8,6x + 1 > 3(x + 1).

Крок 1. Перша нерівність

Розкриваємо дужки: 2x + 6 − 4 < x − 8.

Зводимо подібні: 2x + 2 < x − 8.

Віднімаємо x та 2: x < −10.

Крок 2. Друга нерівність

Розкриваємо дужки: 6x + 1 > 3x + 3.

Переносимо доданки: 3x > 2, тому x > 2/3.

Крок 3. Перевіряємо, чи є перетин

Перша умова вимагає, щоб x було менше за −10. Друга — щоб x було більше за 2/3. На одній координатній прямій видно, що ці проміжки розташовані окремо й не мають спільної частини.

x < −10x > 2/3Спільної частини немає

Відповідь: розв’язків немає (∅).

Це важливий випадок: не кожна система має розв’язки. Якщо проміжки не перетинаються, їх перетин — порожня множина.
🔢 Наступний тип завдань

Як знаходити цілі розв’язки системи

Спочатку розв’яжи систему й отримай проміжок. Лише після цього випиши цілі числа, які належать проміжку.

Приклад за типом вправи № 7.17 (1)

{x5 > x + 16,2(x + 1) + 5 > 3(x − 5) + 14.

1. Перша нерівність

Множимо обидві частини на 30 (додатне число, тому знак не змінюється): 6x > 5(x + 1).
6x > 5x + 5.
Звідси x > 5.

2. Друга нерівність

Розкриваємо дужки: 2x + 2 + 5 > 3x − 15 + 14.
2x + 7 > 3x − 1.
Звідси x < 8.

3. Перетин і цілі числа

Перша нерівність дала x > 5, друга — x < 8. Позначимо обидва проміжки на одній координатній прямій: синій — перша нерівність, помаранчевий — друга, зелений — їхній перетин.

Перша нерівність: x > 5Друга нерівність: x < 8Перетин

Отже, спільний проміжок: 5 < x < 8, або x ∈ (5; 8). Тепер вибираємо цілі числа всередині нього: 6 і 7.

Відповідь: 6; 7.

Тренування

Тренувальна вправа 2

Знайди цілі розв’язки системи, якщо після розв’язування отримано 1 < x ≤ 5.

Як шукати найменше або найбільше ціле число

У № 7.20 потрібно знайти найменше ціле число, а в № 7.21 — найбільше. Після розв’язування системи уважно подивись на межі проміжку: чи включені вони, і які цілі числа лежать усередині.

Розбір за типом № 7.20 (1): знайти найменше ціле число

Перша нерівність: 5(2x − 1) + 3 > 2(x − 1) + 7x.

10x − 5 + 3 > 2x − 2 + 7x.
10x − 2 > 9x − 2.
x > 0.

Друга нерівність: 6(1 − x) + 2 ≥ 3(x + 1) − 7x.

8 − 6x ≥ 3x + 3 − 7x
8 − 6x ≥ 3 − 4x
5 ≥ 2x
x ≤ 2,5.

Отже, 0 < x ≤ 2,5. Цілі розв’язки: 1 і 2. Найменше ціле число — 1.

№ 7.31. Третя сторона трикутника

Одна сторона трикутника дорівнює 4 см, друга — 5 см. Периметр менший за 15 см. Якою може бути третя сторона?

Крок 1. Познач третю сторону через x см.
Крок 2. За нерівністю трикутника: x > 5 − 4, тобто x > 1.
Крок 3. Периметр менший за 15: 4 + 5 + x < 15, тому x < 6.
Крок 4. Об’єднуємо умови: 1 < x < 6.

Відповідь: третя сторона більша за 1 см і менша за 6 см.

№ 7.32. Маса ящика з помідорами

Першу машину завантажили 2 ящиками огірків по 24 кг і 8 ящиками помідорів. Загальна маса не більша за 260 кг. Другу машину завантажили 3 ящиками цибулі по 18 кг і 7 такими самими ящиками помідорів. Загальна маса не менша за 230 кг.

Крок 1. Нехай x — маса одного ящика помідорів у кілограмах.
Крок 2. Перша машина: 2 · 24 + 8x ≤ 260
48 + 8x ≤ 260.
8x ≤ 212.
x ≤ 26,5.
Крок 3. Друга машина: 3 · 18 + 7x ≥ 230
54 + 7x ≥ 230.
7x ≥ 176.
x ≥ 1767, тобто x ≥ 25 17.
Крок 4. Разом: 25 17 ≤ x ≤ 26,5. Якщо x — ціле число кілограмів, можливе значення — 26.

Аліса купила записник за 80 грн і 5 ручок, заплативши менше ніж 114 грн. Аліна купила скетчбук за 72 грн і 4 такі самі ручки, заплативши більше ніж 92 грн. Знайди ціну ручки, якщо вона ціла кількість гривень.

Крок 1. Нехай x — ціна однієї ручки в гривнях.
Крок 2. Аліса: 80 + 5x < 114.
5x < 34.
x < 6,8.
Крок 3. Аліна: 72 + 4x > 92.
4x > 20.
x > 5.
Крок 4. Разом: 5 < x < 6,8. Єдине ціле значення — 6.
